# Maths League

A gamified mathematics learning platform for students and educators.

## V1 mobile foundation
- Student dashboard with XP, streaks, rank and progress
- Learning topics and lesson progress
- Daily, live and practice test hub
- Competitive leaderboard
- Maths games hub
- Admin supervision dashboard foundation
- Expo Router / React Native foundation for Android and iOS

## Run locally

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go for development. Expo supports Android and iOS from the same codebase. For installable store builds, configure EAS and run `eas build --platform all`.
